## 分析方法說明

### 等價劃分 (EP)

將輸入值分為若干等價類別，每一類中的任意值理論上會產生相同的行為：
- **有效等價類 (Valid EC)**：系統應接受的合法輸入
- **無效等價類 (Invalid EC)**：系統應拒絕的非法輸入

### 邊界值分析 (BVA)

針對每個等價類的邊界，測試以下五個點：
- **min-1**：下界以下（無效）
- **min**：下界（有效）
- **nom**：典型值（有效）
- **max**：上界（有效）
- **max+1**：上界以上（無效）

### 符號說明

| 符號 | 說明 |
|------|------|
| ✅ | 已有測試覆蓋 |
| ❌ | 缺少測試（需補充） |
| ⚠️ | 部分覆蓋（可加強） |
