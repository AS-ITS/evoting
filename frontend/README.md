# Frontend 前端套件

套件均以預先建置資產提供；本專案安裝、CI 與執行不使用 npm/yarn，因此不納入上游僅供建置的 devDependency lockfile。

本專案 **MIT**。對話框使用 `kartik-v/yii2-dialog` 與 Bootstrap 5 Modal。

| 目錄 | 版本 | 用途 |
| --- | --- | --- |
| AdminLTE3_ComVer | 1.0 | 依 AdminLTE 調整的專案樣式 |
| [bootstrap-select](https://github.com/snapappointments/bootstrap-select/) | 1.13.18 | 下拉選單 |
| [bootstrap-steps](https://github.com/ycs77/bootstrap-steps) | 1.0.3 | 步驟列 |
| [highlight.js](https://highlightjs.org/) | 11.11.1 | 語法高亮 |
| [highlightjs-curl](https://github.com/highlightjs/highlightjs-curl) | 1.3.0 | highlight.js 的 cURL 語言 |
| [OverlayScrollbars](https://github.com/KingSora/OverlayScrollbars) | 1.13.1 | 自訂捲軸 |
| [Sortable](https://github.com/SortableJS/Sortable) | 1.15.7 | 拖放排序 |
| [summernote](https://summernote.org/) | 0.8.18 | WYSIWYG 編輯器 |

AdminLTE 本體由 Composer `bower-asset/adminlte` v3.1.0 提供，不在此目錄。
