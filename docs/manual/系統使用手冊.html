1. 前言與注意事項

本手冊說明後台管理者如何建立與執行投票場次。建議依「作業流程總覽」章節順序設定；各功能細節見後續章節。

注意事項

  1. 網址與存取路徑（依 Web Server 與 .env 設定而定，詳見 SETUP.md、CONFIGURATION.md）：
    • 投票首頁：https://{您的網域}/（Document Root 應指向專案的 web/ 目錄）
    • 管理者登入：https://{您的網域}/admin
    • 場次短網址：https://{您的網域}/{短網址編號}（於投票編輯頁設定）
    • 環境識別：由 .env 的 APP_ENV（production / testing / development）決定
    • 必須在 .env 設定 ALLOWED_HOSTS（逗號分隔，支援萬用字元），否則所有請求會被拒絕
  2. 分組專屬網域轉址（選用，於 Web Server 設定）：
    • 可為各分組設定獨立網域，透過 nginx/Apache 轉址至對應場次的短網址
    • 例：https://group-a.example.com → https://voting.example.com/abc123
    • 變更短網址編號時，需同步更新 Web Server 轉址規則

2. 作業流程總覽

依下列順序建立與執行一場投票。灰色項目為選用。

  1. 建立／編輯場次（類型、分組、時間、流程）
  2. 輪次（單輪可略；多輪時於選票產生後再建下一輪）
  3. 問題與投票規則（含選用：投票母數）
  4. 候選名單與畫面配置
  5. 密碼（僅匿名投票）→ 啟用後開放投票
  6. 選票（查詢／補登／匯入）
  7. 計票 → 開票 → 結果
  8. 重啟／列印簽名（選用）

投票時間與投票狀態

兩者連動，決定投票者能否登入投票：

  1. 投票狀態等於等待，投票登入頁面訊息顯示: 目前投票尚未開始。
  2. 投票狀態等於進行，且當下時間小於投票時間(起)，無法投票，投票登入頁面訊息顯示: 目前投票尚未開始。
  3. 投票狀態等於進行，且當下時間大於等於投票時間(起)，且小於等於投票時間(迄)，可以投票，投票登入頁面訊息顯示: 開始投票，請輸入場次碼及線上投票密碼。
  4. 投票狀態等於截止，或當下時間大於投票時間(迄)，無法投票，投票登入頁面訊息顯示: 目前投票已結束。
  5. 投票狀態等於補登，且當下時間大於等於投票時間(起)，且小於等於投票時間(迄)，可以投票，投票登入頁面訊息顯示: 開始進行補登／紙本計票作業，請輸入場次碼及線上投票密碼。

※ 投票時間(迄)就是計票的日期。

投票類型

  • 表決（無須驗證）：不需登入驗證即可投票。
  • 匿名（亂數密碼）：透過系統生成的亂數密碼登入投票。

是否分組

  • 分組
    • 至多分成4組（上限可由「網站設定 → 分組上限」調整），各組分組名稱於場次編輯時自訂。
    • 另有部署端組織 preset（config/params.php 的 ct.division*Ary），與場次自訂分組名稱並行，詳見 SETUP／CONFIGURATION。
    • 不同分組可以有分組自己的問題，也可以有不同分組間的共同問題。
    • 匿名投票的密碼根據分組生成。
    • 開票可以設定不同分組僅能查看該分組的投票結果。
  • 不分組
    • 分組名稱為預設。

保留名額

  • 女性保留名額: 最後開票結果，性別設定為女性候選人，要大於等於問題設定的女性保留人數。

投票結果顯示

  • 僅分組可以設定。
  • 所有分組: 投票結果所有分組一起顯示。
  • 僅限同分組: 開票可以設定是否分組顯示結果。

是否共用投票密碼與共用密碼之投票

  • 若此投票有分組，分組數量及順序必須與共用密碼的投票相同。
  • 分組投票無法共用不分組投票的密碼。

群組

讓特定群組的成員可以管理該場次的投票。

投票管理者

  • 建立這場投票的人。
  • 投票活動管理者可以選擇其他具系統權限的管理者。
  • 系統管理者可以選擇所有具系統權限的管理者。

場次碼

登入投票需要輸入的資料，未設定則不啟用。

短網址編號

  • 透過 https://{您的網域}/{短網址}，可以直接指向該投票場次。
  • 系統管理者可以修改。

顯示及流程

投票狀態

  • 同投票時間與投票狀態
  • 投票狀態會顯示在標題右上角(如下圖紅框處)

投票完成跳轉頁面

投票完成、投票結束尚未送出投票後導向的頁面

是否略過投票資訊頁面

  • 投票資訊頁指的是vote/vote-detail頁面。
  • 選擇是，vote/vote-detail路由會直接導向投票頁面(vote/start-vote)
  • 如果有上傳附件，附件會在投票資訊頁中顯示，所以如果要讓使用者看到附件，必須選否。

查看投票資訊是否驗證

  • 如果略過投票資訊頁面選擇是，則忽略此設定。
  • 投票資訊指的是vote/vote-detail路由。
  • 意思就是訪問vote/vote-detail頁面是否要先登打投票密碼。

是否略過圈選結果頁

以公版來說，再次進入投票頁面(vote/start-vote)，如果已經完成投票，會導向圈選結果頁(vote/check-ballot)，但若流程不需讓投票者回看圈選結果，可設為略過，送出後直接導向投票完成頁，所以會直接導向投票完成跳轉頁面。

是否於首頁顯示

  • 此投票場次的連結是否於首頁(vote/index)顯示。
  • 如果網站設定的首頁導向網址有資料，則無視此設定，因為首頁都會導向首頁導向網址。

候選名單配置

  • 依投票場次統一: 只會有一個候選名單配置，所有問題共用。
  • 依問題個別設定: 每個問題可有獨立的候選名單配置。

投票列表排序

影響投票場次列表與首頁的排序，僅系統管理員可更改。

5. 問題

問題用來區分不同類別的候選名單，各自擁有獨立的投票規則。分組場次可設組內問題或共同問題。

  1. 問題是投票頁面區別不同類別候選名單的功能。
  2. 各問題會顯示在投票頁面的最上方(如圖1)。
  3. 一個投票場次可以有多個問題，各分組有屬於自己的問題(如圖2)。
  4. 共同問題是所有分組都要圈選的，所有分組一起統計選票；共同問題隸屬的分組叫做共同投票。
  5. 每個問題都有獨立的投票規則。

欄位說明

欄位說明
組別僅「是否分組＝是」時出現。選特定分組則僅該組可見；選「共同投票」則所有分組可見並合併統計。
標題／英文標題問題顯示名稱，可使用 HTML。
描述／英文描述補充說明文字（見下圖）。
自定義未圈選顯示名稱下限為 0 且未圈選時，確認步驟的顯示文字（預設為標題）。
自定義投票規則文字覆蓋自動產生的規則說明文字。

問題投票規則（有效／廢票）

  • 這裡的投票規則才是真正影響有效票或廢票的設定。從下拉式選單選擇組別，會自動帶入編輯的投票規則的設定數字。勾選自訂規則可以自由輸入數字。

未設定自訂投票規則文字時，系統依上下限自動帶出說明文字：

條件顯示文字
無上下限（上限 ≧ 候選總數且下限 = 0）本次投票圈選名額無限制。
僅有上限不得超過 {最多可投票數}{名稱的單位}。
僅有下限不得少於 {最少應投票數}{名稱的單位}。
上下限皆有不得少於 {最少應投票數}，亦不得多於 {最多可投票數}{名稱的單位}。

投票母數

  • 代表該問題所屬分組的「應有投票人數」（例如該組全體有投票權的人數），與「啟用密碼數量」（實際可投票／已發放的票數）不同。
  • 供紀錄用；可依實際需求填寫，不影響有效／廢票判定與開票。

匯入輪次問題

  • 匯入前N個輪次建立的問題。
  • 在頁面修改要匯入問題的投票規則。
  • 該問題的候選名單配置會一併匯入。
  • 點擊右上角的紅色叉叉按鈕刪除不需要匯入的問題。

候選名單管理

手動新增

單筆新增候選名單，上傳照片只能手動新增時操作。

檔案導入

透過CSV檔案上傳的方式，批次匯入候選名單，頁面上有4個頁籤。

  1. 進入範例下載頁籤下載範例CSV檔案。

導入問題: 要匯入的當前輪次的問題。

候選人: 候選人問題選擇後會出現。勾選指定候選人設定已達門檻，其餘直接導入。

紅字括號是輪次1的得票排名，沒有排名表示前一輪已達門檻。

候選名單配置

設定投票頁面候選名單呈現樣式，可以依照問題個別設定。

基本設定

編號顯示:

  • 顯示自動編號: 依照表格順序加入數字，從1開始。
  • 顯示自訂義編號: 顯示候選名單自訂排序的數字。

寬度: 決定候選名單表格的寬度，如下圖，上寬下窄。

投票時候選名單顯示列數: 候選名單要分成幾個表格呈現，下圖是設定為2的效果，上圖則是設定為1的效果。

※ 如果候選名單要排序，必須設定為1。

使用欄位表頭:

  • 候選名單表格的表頭是否要再加上一層表頭。
  • 選擇是，儲存後才會出現欄位表頭的設定區域。
  • 需要搭配欄位顯示、排序的設定才會顯示。

名稱顯示文字: 影響候選人姓名這個欄位的表頭顯示的文字。

名稱的單位: 影響投票頁面右上角及確認頁面已勾選的候選人數字的單位。英文如果為複數會自動加s。位置如下圖紅框所示:

文字大小: 表格內文字的尺寸，一定要填單位，px、em、rem等等。

表格高度: 表格儲存格的高度，一定要填單位，px、em、rem等等。

表格標頭顏色:

  • 表頭的顏色，包含使用欄位表頭，請使用含井字號的16進制色碼。
  • 若投票時候選名單顯示列數大於1，可以用半形逗號區隔多個色碼達到下圖效果。

是否使用排序: 只有投票時候選名單顯示列數設定為1才有效，搭配排序的欄位設定那些欄位要排序，目前只有姓名、自定義名稱可以排序。

預設排序的欄位: 不選擇則按候選名單排序，只能選要排序的欄位。

7. 密碼

僅匿名投票使用。產生、啟用密碼後方可讓投票者登入。共用密碼場次請見下方限制。

  • 僅有匿名投票可以操作，透過生成條件的密碼批次產生密碼。
  • 共用密碼場次：可設定狀態、密碼匯出、生成密碼函、列表查詢；不可在本場次生成或刪除密碼（密碼池屬於被綁定的主場次）。批次變更狀態會影響所有綁定該密碼池的場次。
  • 共用密碼會在表格上方顯示共用哪個場次的密碼，如下圖所示。
  • 共用密碼的條件請參考是否共用投票密碼與共用密碼之投票。

密碼列表與遮罩

  • 列表「密碼」欄預設顯示 密碼#編號（遮罩），不含明文。
  • 按工具列 顯示明文，完成二次驗證後，列表於時效內（預設 15 分鐘）顯示明文；可按 立即鎖定 提前結束。
  • 明文亦可透過下方「密碼匯出」「生成密碼函」取得（同樣需二次驗證）。

本輪已投票

  • 列表欄位「本輪已投票」表示：目前場次、目前輪次是否已有選票（以選票資料為準），不是資料庫內 legacy 的 passwords.voted 欄位。
  • 可於列表篩選、設定狀態、密碼匯出、生成密碼函條件中指定「本輪已投票」是/否。
  • 多輪次投票時，切換輪次後「本輪已投票」會隨目前輪次改變。

13. 二次驗證與雙因素驗證

系統對高敏感管理操作要求二次驗證（輸入目前登入的管理員密碼）。若帳號已啟用 TOTP，另須輸入驗證器 6 碼。由環境變數 SENSITIVE_REAUTH 控制（正式環境預設開啟；僅測試環境可關閉）。

TOTP 綁定步驟

  1. （維運）執行 docs/migrations/20260713_users_totp.sql。
  2. 登入後台 → 使用者管理 → 雙因素驗證。
  3. 輸入管理員密碼 → 掃描 QR Code → 輸入 App 顯示的 6 碼完成啟用。
