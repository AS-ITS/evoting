# 操作日誌（logs）生命週期政策（草案）

> **狀態**：Phase 3.1 制度化草案（2026-07-09）  
> **核准**：待資安 + 維運簽核  
> **相關**：[`系統維護手冊.md`](系統維護手冊.md) §5、[SECURITY.md](../../SECURITY.md)

---

## 1. 目的

定義 `logs` 及相關表之保留、歸檔與刪除原則，平衡**稽核需求**與**個資/匿名性**風險。

---

## 2. 適用範圍

| 資料 | 說明 |
|------|------|
| `logs` | Web / Console 操作稽核（含 500/501 匿名登入、420/421 Console） |
| `logins` | 匿名投票者 session（非 logs 表） |
| `runtime/logs/` | Yii 應用程式檔案日誌 |

---

## 3. 保留期限（建議）

| 資料 | 線上保留 | 歸檔 | 刪除 |
|------|----------|------|------|
| `logs` | 當屆選舉結束後 **2 年** | 冷儲存（加密備份）再 **3 年** | 歸檔期滿後銷毀 |
| `logins` | 場次 `active` 截止後 **90 天** | 不歸檔 | 逾期清除 |
| `runtime/logs/` | **90 天** | 不歸檔 | logrotate 刪除 |

**例外**：司法或稽核需求得延長保留，須變更單核准。

---

## 4. 內容與備份

1. **禁止**將含可還原投票密碼的 `passwords.passwd` 明文與 `logs` 打包至同一未加密備份對外流通。
2. 匿名登入 log（500/501）自 2026-07 起**不得**含明文投票密碼；歷史 log 已刪除。
3. 歸檔 `logs` 前得遮罩 IP 末段（選用）。

---

## 5. 執行責任

| 工作 | 負責 |
|------|------|
| 政策維護 | 資安（A）、維運（R） |
| 排程歸檔 / 刪除 | 維運 |
| 選舉結束後複審 | 選務 + 維運 |
